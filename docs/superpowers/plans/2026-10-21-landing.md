# Лендинг «ИИ-практики из Беларуси» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Одностраничный лендинг для белорусского собственника бизнеса, который за 10 секунд объясняет «найдём практика, который автоматизирует ваш процесс с помощью ИИ» и ведёт в Telegram Анатоля.

**Architecture:** Один статический `index.html` с внутренним `<style>`, без JavaScript. Рядом лежит сжатый `portrait.png`. Страница — одна колонка из пяти `<section>` с фиксированными `id`. Каждая задача заполняет свои секции и дописывает свои тесты в общий файл тестов.

**Tech Stack:** HTML5, CSS (custom properties, без фреймворков). Тесты на Python 3.9 stdlib (`unittest`, `html.parser`, `urllib.parse`). Портрет готовится через ImageMagick (`/opt/homebrew/bin/magick`). Проверка с телефона — Playwright MCP (`mcp__playwright__*`), запасной вариант — headless Google Chrome.

**Spec:** `docs/superpowers/specs/2026-10-21-landing-design.md` — прочитать перед задачей.

Все пути ниже — относительно корня репозитория `/Users/claude1/Work/StartUp/landing`. Тесты запускаются из корня: `python3 -m unittest discover -s tests -v`.

## Global Constraints

- Один файл `index.html` в корне, все стили в одном `<style>` в `<head>`. Никаких `<script>`, `<link rel="stylesheet">`, `@import`, `url(http…)`, внешних шрифтов и картинок.
- Единственные внешние адреса — ссылки `https://t.me/ahtlv?text=…`. Единственный другой файл, на который ссылается страница, — `portrait.png`.
- `<html lang="ru">`, `<meta charset="utf-8">`, `<meta name="viewport" content="width=device-width, initial-scale=1">`.
- Обращение на «вы», тон тёплый и спокойный, простые слова. Без жаргона (LLM, агент, промпт) и без слова «трансформация».
- Нет цен, отзывов, кейсов, логотипов клиентов. Факты только такие: Анатоль Хотулёв; автор курса «Claude Code: от нуля до уверенной работы», 70+ выпускников; выпускники — белорусские специалисты, живут в Беларуси; основатель Web3 Belarus (W3B), 2 500+ участников; 15+ лет в маркетинге и предпринимательстве.
- «Claude Code» не упоминается в `#hero`, только в `#about`.
- Цвета (CSS custom properties на `:root`, имена фиксированы): `--bg: #FAF6F0`, `--bg-alt: #F1E7DA`, `--line: #E8DFD3`, `--text: #2B2622`, `--muted: #5C534C`, `--accent: #B4532A`, `--accent-ink: #9A4420`. `--accent-ink` — для hover кнопки и для меток на фоне `--bg-alt`: у `--accent` на `--bg-alt` контраст всего 4.08.
- Шрифты: заголовки `Georgia, "Times New Roman", serif`, текст `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.
- Ширина контента не больше 680 px, на телефоне (от 360 px) без горизонтальной прокрутки. Тёмной темы нет.
- Готовые тексты Telegram (в `href` URL-кодированы через `encodeURIComponent`-эквивалент, конечный пробел сохраняется):
  - `HERO_TEXT = "Здравствуйте! Я с сайта ИИ-практиков. Хочу автоматизировать процесс в бизнесе: "`
  - `CTA_TEXT = "Здравствуйте! Я с сайта ИИ-практиков. Первым хочу отдать ИИ такой процесс: "`
- Коммиты заканчиваются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Телефон 360 px и длинные русские слова** («автоматизирует», «предпринимательстве»): заголовок и кнопки не вылезают за экран, горизонтальной прокрутки нет. Тест: `test_wrapping_rules` (задача 1) и проверка `scrollWidth` (задача 5).
2. **Кириллица в ссылке Telegram:** при декодировании `href` должен совпадать с готовым текстом символ в символ, иначе в Telegram придёт мусор. Тесты: `test_hero_button`, `test_cta_button` (задачи 2 и 4).
3. **Контраст:** белый на терракоте, второстепенный текст и метки должны давать ≥ 4.5. Тест: `test_palette_contrast` (задача 1).
4. **Клавиатура:** у кнопок видимый фокус. Тест: `test_focus_visible` (задача 1).
5. **Портрет не загрузился или грузится медленно:** есть `alt`, заданы `width`/`height`, чтобы вёрстка не прыгала, файл ≤ 150 КБ. Тест: `test_portrait` (задача 4).
